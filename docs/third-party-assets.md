# Bundled assets

The interface uses locally bundled fonts so the lessons do not request assets from a font service.

- **DM Sans** is distributed under the SIL Open Font License 1.1. The full notice is preserved in [DM-Sans-OFL.txt](../public/licenses/DM-Sans-OFL.txt).
- **Manrope** is distributed under the SIL Open Font License 1.1. The full notice is preserved in [Manrope-OFL.txt](../public/licenses/Manrope-OFL.txt).

Vite copies these notices into the published site's `licenses/` directory. Fonts are installed through their Fontsource packages. Icons come from `lucide-react`; dependency license notices remain available in the installed npm packages. The lesson illustrations and plots are SVG rendered from this repository's code.
